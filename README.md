# Посты Claude для @dasha_ras4eshi

Отсюда автопостер @ras4eshi_poster_bot (сервер Timeweb) забирает пост на день,
если в его очереди нет поста Даши.

- `posts/ГГГГ-ММ-ДД.md` — текст поста на эту дату (обычный текст, без разметки).
- `posts/ГГГГ-ММ-ДД.img` — необязательно: одна строка, прямая ссылка на картинку.
- `posts/ГГГГ-ММ-ДД.jpg` — необязательно: картинка файлом (приоритетнее .img).

Публикация в 10:15 МСК. Команда боту `/claude` выпускает сегодняшний пост сразу.
Чтобы отменить пост Claude на день — удалите файл или пришлите боту свой пост.
